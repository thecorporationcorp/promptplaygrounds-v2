What Are Bookmarklets?

Bookmarklets are special bookmarks that run JavaScript code instead of opening a webpage. They're safe, fast, and work in any browser.

When you click a bookmarklet, it executes code on the current page - in our case, it injects a pre-written prompt into your AI chat interface.

Step 1: Get Access

  1. Pay 99¢ on our homepage via Ko-fi
  2. Receive an access code via Ko-fi message
  3. Enter the code on our site to unlock the library
  4. Lifetime access - no recurring fees

Step 2: Show Your Bookmarks Bar

Chrome / Edge / Brave:

  • Windows: Press Ctrl + Shift + B
  • Mac: Press Cmd + Shift + B

Firefox:

  • View → Toolbars → Bookmarks Toolbar

Safari:

  • View → Show Favorites Bar or Cmd + Shift + B

Step 3: Install Bookmarklets

Browse the Prompt Library and find prompts you want to use.

  1. Click on a prompt to view details
  2. Click "Get Bookmarklet" (some are free, some cost $0.99-$12)
  3. Drag the bookmarklet button to your bookmarks bar
  4. That's it! The bookmarklet is installed
Tip: Create a folder in your bookmarks bar called "AI Prompts" to organize all your bookmarklets in one place.

Step 4: Use Your Prompts

  1. Go to ChatGPT, Claude, or any AI chat interface
  2. Click the bookmarklet in your bookmarks bar
  3. The prompt auto-loads into the input field
  4. Add your specific details and send!
That's it! You can use bookmarklets unlimited times. They work offline and never expire.

Troubleshooting

Bookmarklet doesn't work?

  • Make sure you're on ChatGPT or Claude (or another AI chat)
  • Try refreshing the page and clicking again
  • Some sites block bookmarklets - try a different AI chat

Can't see bookmarks bar?

  • Use the keyboard shortcut listed in Step 2
  • Check your browser's View menu

Didn't receive access code?

  • Check your Ko-fi messages/notifications
  • Check spam folder if sent via email
  • Contact us if still missing after 24 hours
